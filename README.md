# ArtisyHub — шинэ загвар

ArtisyHub.mn-ийн одоогийн Angular 16 төсөл дээр хийсэн шинэ дизайн.
Энэ нь уран бүтээлчдийн үйлчилгээ танилцуулж, захиалгыг ArtisyHub апп руу
чиглүүлдэг веб. Шинэ backend, төлбөрийн систем, нэвтрэх систем оруулаагүй.

## Шууд нээж үзэх

`ArtisyHub-preview.html` файлыг Chrome, Edge, Safari эсвэл Firefox дээр нээнэ.
Нэг файл дотор үйлдвэрлэлийн build, зураг, фонт бүгд орсон.
Төрлөөр шүүх, цэс, нийтлэлүүд, асуулт-хариулт ажиллах зориулалттай.
Гаднын App Store, Google Play, сошиал холбоосууд интернэт шаардана.
Файлын горимд hash route, сервер дээр хэвийн `/home`, `/news` route ашиглана.
Энэ орчинд браузерийн бодит шалгалт хийх боломж хориглогдсон тул харагдац,
харилцан үйлдлийг браузерт баталгаажуулсан гэж үзэж болохгүй.

## Хөгжүүлэлт

```sh
npm ci
npm start
```

Angular 16-ийн дэмждэг Node.js хувилбар шаардлагатай. Framework-ийн том
хувилбарын шинэчлэл энэ дизайны ажлын хүрээнд хийгдээгүй.
`package.json`, `package-lock.json` дахь dependency хувилбарууд хадгалагдсан.
ZIP-д `node_modules`, `.angular` cache ороогүй; `npm ci`-аар сэргээнэ.

## Build

```sh
npm run build
python3 scripts/create-preview.py
```

Серверт байршуулах файлууд `dist/` дотор гарна. Offline preview үүсгэхэд
Python 3 шаардлагатай; нэмэлт Python сан хэрэггүй.

## Өөрчлөлт

- Брэндийн ягаан, нил ягаан өнгө, эх кодын бодит зураг, логог ашигласан дизайн.
- Шинэ нүүр хуудас, 8 уран бүтээлчийн танилцуулга, төрлөөр шүүх үйлдэл.
- Гар утасны цэс, гарын Tab товчоор ашиглах холбоосууд, skip link,
  хөдөлгөөн багасгах тохиргоог дэмжсэн загвар.
- Дөрвөн алхамтай захиалгын тайлбар, төлбөрийн баталгаа, апп татах хэсэг.
- Мэдээ, 6 нийтлэл, давуу тал, бидний тухай, FAQ-ийн хуудсууд шинэчлэгдсэн.
- Өмнөх холбоосууд болон цуцлалтын бизнес нөхцөл хадгалагдсан.
- Монгол хэлний metadata, хуудас бүрийн title, sitemap-ийн дутуу route зассан.
- Байхгүй `/search` үйлдлийн structured data хассан.
- Хэрэггүй Flowbite DOM initialization хассан; dependency өөрөө хэвээр.
- Огноо нь тодорхойгүй, кодод хатуу бичсэн хэрэглэгч/артистын тоог
  шинэ дизайнд нийтлээгүй. Үнэлгээ, үнэ, боломжит цаг шинээр зохиогоогүй.

## Өгөгдөл шинэчлэх

`src/app/shared/content.ts` — уран бүтээлчид, аппын холбоос, FAQ, нийтлэлийн жагсаалт.
Эндхийн уран бүтээлчид нь эх кодын зургаар хийсэн танилцуулгын сонголт;
бүрэн каталог эсвэл бодит цагийн availability биш.

`src/styles.scss` — фонт, өнгө, responsive layout, нийтлэг компонентын дизайн.

## Байршуулах

`vercel.json` нь Angular build болон шууд route нээх SPA fallback тохиргоотой.
Одоогийн `artisyhub.mn` домэйнд энэ хувилбарыг нийтлээгүй.
Эхлээд Vercel Preview дээр компьютер, гар утас, холбоосын шалгалт хийж,
зөвшөөрсний дараа production-д нэвтрүүлэх боломжтой.

Өмнөх `.github/workflows/static.yml` нь бүх repository-г Pages рүү хуулдаг
хуучин workflow тул шинэ дизайны deploy-д ашиглахгүй; энэ архивт эхээрээ бий.
Vercel ашиглахдаа дээрх build болон `dist/` output-ыг ашиглана.

## Баталгаажуулалт

Энэ хувилбарын build, TypeScript болон локал asset/route шалгалтын үр дүнг
`VALIDATION.md` файлаас харна уу. Браузерээр харагдац, interaction шалгах,
Vercel дээр шууд route refresh шалгах нь тусдаа баталгаажуулалт шаардлагатай.
